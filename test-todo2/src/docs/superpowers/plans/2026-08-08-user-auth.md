# User Authentication Implementation Plan

**Goal:** Add JWT-based user authentication to the test-todo2 Go service, protecting all existing endpoints.

**Architecture:** Contracts-first approach (tg v3). New `UserService` contract generates transport. Auth middleware guards existing routes. SQLite `users` table. In-memory rate limiter and CSRF double-submit cookie.

**Tech Stack:** Go 1.26, tg v3 codegen, golang-jwt/jwt/v5, golang.org/x/crypto/bcrypt, SQLite (modernc.org)

## Global Constraints

- All new files inside `test-todo2/src/`
- Go builds via `go build ./...`, tests via `go test ./...`
- Transport generated by `tg server -o internal/transport`
- Passwords bcrypt-hashed, tokens never logged
- Env vars: AUTH_ACCESS_TTL, AUTH_REFRESH_TTL, AUTH_SECRET, AUTH_LOGIN_RATE, AUTH_CSRF_SECRET
