# PRD 005: Реализация формы логина пользователя

## Goal

Добавить отдельнуюс страницу с формой входа пользователя. И перенос всего текущего функционала в зону после аутентификации.
Только зарегистрировавшийся пользователь способен создавать кабинеты и создавать todo.

## Functional requirements — backend
- создать отдельный интерфейс для работы с пользователями
- создать метод self-registration с csrf защитой
- иметь возможность пройти аутентификацию по логину и паролю
- механиз аутентификации должен работать на основе JWT токена с поддержкой refresh
- время жизни токена должно быть настраиваемо
- пароли должны храниться в хешированном виде
- должна быть уникальность по логину в виде email
- поддержать soft delete по пользователям

## Functional requirements — Web UI (MANDATORY)
- форма логина с кнопкой войти
- кнопка выйти
- валидация для логина
- валидация для сложности пароля

## Non-functional requirements

- при часто вводе пароля дожен срабатывать rate-limit который должен настраиваться
- должна быть отдельная таблица под пользователей

## Deliverables (in this src/ directory)

- добавить отдельный интерфес для логина
- доработать web часть в нее добавить кнопку выхода
- зафиксировать все изменения и логику работы в wiki в секции работа с лк
- создаются таблицы

## Definition of done

- все тесты для фронтенда проходят
- все тесты для бекенда проходят
- появлятеся форма входа
- создаются заявки с веб интерфейса в рамках разных профилей
