# PRD 004: Реализация web интерфейса личного кабинета

## Goal

Добавить для web интерфейса переключатель между всеми личными кабинетами которые есть в системе

## Functional requirements — Web UI (MANDATORY)
- должен быть дропдаун в котором выводится список ЛК и между ними можно переключаться
- подключить методы из секции profile для создания профиля и для переключения между ними

## Non-functional requirements

- при переключении между лк должны перезагружаться все доступные записи

## Deliverables (in this src/ directory)

- добавить отдельный интерфес для работы с ЛК
- доработать web часть ид обавить новые компоненты
- зафиксировать все изменения и логику работы в wiki в секции работа с лк

## Definition of done

- все тесты для фронтенда проходят
- появились компоненты для переключениям между профилями
- создаются заявки с веб интерфейса в рамках разных профилей
