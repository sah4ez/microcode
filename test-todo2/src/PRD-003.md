# PRD 003: Добавление личного кабинета

## Goal

Добавить личный кабинет (лк), между которыми можно будет переключаться и внутри котого можно вести все завявки. Например создать 2 лк с разными названиями (например работа и дом) и в них создать 2 списка разных, и между ними можно переключаться.

## Functional requirements

- создать методы группы `/personal-profile` в которой создать методы работы с ЛК (CRUD)
- для методов создания и получения todo нужно передавать в заголовках x-lk-id по которому будет проходить авторизация доступа к ресурсу
- ЛК должны храниться в отдельной таблице в бд
- все старые данные удалить и создать с нуля

## Functional requirements — Web UI (MANDATORY)
- должен быть дропдаун в котором выводится список ЛК и между ними можно переключаться

## Non-functional requirements

- при переключении между лк должны перезагружаться все доступные записи

## Deliverables (in this src/ directory)

- добавить отдельный интерфес для работы с ЛК
- доработать методы для работы с todo
- доработать web часть ид обавить новые компоненты
- зафиксировать все изменения и логику работы в wiki в секции работа с лк

## Definition of done

- go test проходят все тесты
- curl с заголовками x-lk-id возвращает только доступные записи
- при переключении в dropdown компопненте начинают отправлять выбранные x-lk-id
