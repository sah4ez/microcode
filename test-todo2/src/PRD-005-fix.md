# PRD 005 fix: Исправление всех этапов сборки и запуска

## Контекст (стек)

Это Go-сервис на `github.com/loki/todoservice` (модуль в `test-todo2/src/`):
- **Контракты** описаны `@tg`-аннотированными интерфейсами в `contracts/` и
  `contracts/dto/`; HTTP-транспорт (fiber) **генерируется** командой
  `tg server -o internal/transport`. Новые методы добавляются В ПЕРВУЮ
  ОЧЕРЕДЬ в контракты — сгенерированный транспорт обновляется регенерацией.
- **Бизнес-логика** — в `internal/service/service.go`; **хранилище** —
  `internal/storage/sqlite/sqlite.go` (modernc.org/sqlite, чистый Go).
- **Web UI** — vanilla JS в `static/` (`index.html`, `app.js`, `styles.css`),
  раздаётся как `//go:embed static/*` в `main.go`. Сервер слушает
  `0.0.0.0:8000`.
- Уже есть: `PersonalProfileService` (`/personal-profile` CRUD) и `TodoService`
  (`/todos`, скоуп по `x-lk-id` header). Todo несут `lk_id`.

Все новые файлы — ВНУТРИ `src/` (этого каталога). Go-код собирается
`go build ./...`, тесты — `go test ./...`. Фронтенд-тесты —
`node static/app.test.js` (vanilla, без фреймворка).

## Goal

Добавить аутентификацию пользователей в существующий сервис test-todo2. Все
операции с кабинетами (ЛК) и todo становятся доступными ТОЛЬКО после входа:
аутентифицированный пользователь создаёт/переключает кабинеты и создаёт todo
в рамках своих кабинетов. Исправить все DoD

## Definition of done

- `go vet ./...` и `go test ./...` — зелёные (включая новые auth-тесты)
- `go run .` - отрабатывает
- `curl` - отвечают и работают
- `node static/app.test.js` — фронтенд-тесты зелёные
- `POST /auth/register` создаёт пользователя (пароль в хеше), `POST /auth/login`
  возвращает JWT
- Запрос к `/todos` без токена → `401`; с валидным токеном → работает как раньше
- В браузере: форма входа, после входа — кабинеты/todo; кнопка «Выйти» работает
- Пароль не возвращается ни в одном ответе; rate-limit срабатывает при переборе
